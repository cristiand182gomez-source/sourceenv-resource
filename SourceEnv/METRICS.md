# Contract, metrics and denominators

Commands return the case-specific exact JSON objects from fixture metadata, exit 0 and empty stderr. JSON whitespace and key order are free; duplicate keys, non-finite values, extra content and changed values fail. Help must include the specified tokens. Explicit help exits 0. Implicit help permits 0 or 2 under the channel rules implemented by `oracle.py`; a nonzero exit alone is not failure. No literal source patch or dependency profile is required for acceptance.

**Erratum retained:** `frozen_runtime/policy.json` says “no traceback” in `no_args_channels`. The oracle does not independently enforce a traceback prohibition. This wording is not an extra scored requirement. No frozen bytes were changed to resolve this erratum.

Applications and private grading share the same readonly Bubblewrap launcher with fresh HOME, temporary directory and cache on every invocation. File tools can edit the candidate workspace in a separate trusted worker sandbox. An epoch identity includes source file digests, installed payload, trusted interpreter and relevant environment configuration. Fresh auxiliaries are excluded. Completed capture is required for coverage; transport `ok` alone is insufficient. Public `run_app` feedback omits transport `ok`, retaining it only in private logs. `apply_profile.changed` reflects effective environment identity, not the creation of a new environment directory.

Operational limits per r3 episode: 20 actions, 12 `run_app` requests, 3 parsed `apply_profile` requests, 2,048 generated tokens per reply and 8,192 per episode, context 32,768 including reservation, application timeout 10 seconds, output capture 2 MiB and public view 16 KiB; watchdog 14,400 seconds. Invalid actions consume action budget. Parsed noop/invalid profile requests consume installation budget; the fourth stops the episode without installation. Private scores do not consume agent actions. Model/token limits are vacuous in the scripted baseline, whose counters are exactly zero; no synthetic token counts are reported.

- **Repair:** terminal PASS / available damaged arms. **Healthy preservation:** terminal PASS / available healthy arms, reported separately. Planned denominators are eight and two; unavailable endpoints are never imputed.
- **Modifications:** source/environment requests, effective changes, noops, rejected/failed and unknown effects. Formatting-only changes are not behavior loss. Noop installation is a request, not a repair or effective environment change.
- **Coverage:** completed operations in the current state and cumulative operations. The latest observation replaces an older one; effective changes obsolete all prior current observations. Truncation is preserved. Failure is classified privately and separately as evidentiary public feedback; visibility does not mean understanding.
- **Closure:** valid finish requests and accepted/rejected finishes with current public failures. Missing, obsolete or truncated evidence does not automatically count as a visible failure.
- **Losses:** initially correct checks that fail at the retained terminal, irrespective of source/profile changes. Partial losses and final PASS/FAIL are distinct.
- **Gate exposure:** checkpoints, actual bifurcations, rejection count and FC actions after first rejection. BASE uses its own prefix only. Complete pairs require independent VALID endpoints for both arms. At least 6/8 damaged complete pairs are required for the descriptive paired demonstration. Zero bifurcations means no observed intervention; one or two support case descriptions only, not an inference of no effect.
- **Loops/health:** identical-action streaks, redundant observations of the same operation/state, distinct operations, final stagnation suffix; no-tool replies / received replies, invalid actions / dispatched actions and by type, invalid actions / 20 as budget percentage, terminal and post-rejection actions by type.
- **Costs:** calls, generated-token bounds (reasoning is a subset), input/reservation/context limits, applications and launch bounds, probes, workers, installs, copies, model processes and machine time. Derived BASE adds no model calls; copied-state grading is counted. Ordinary budget terminals are scored; infrastructure faults and censures preserve independent arms and incomplete pairs.

Native textual summaries and explicit finish calls reach the same closure policy. Empty/malformed replies receive explanatory native feedback. Thinking OFF does not guarantee the server returns no spontaneous reasoning. Previous reasoning is not reinserted into messages. r3 configurations used temperature 1.0, top_k 64, top_p 0.95, seed 0, cache_prompt enabled and no penalties.

## Current-epoch modifying requests

`blind_modifying_requests` counts `write_file` and `apply_profile` requests that pass action/argument validation and are issued without a completed `run_app` capture in the current epoch. It includes noops. An effective source/environment change starts a new epoch, so the count does not mean "before the episode's first observation". The name is operational shorthand; it establishes neither intent nor cognition. Historical metric values and implementation are unchanged.
