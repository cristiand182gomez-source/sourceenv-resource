# Historical proposal flags

`r3_proposal.json` is the retained preparation-time proposal, unchanged. Its `PENDING_REVIEW` and false authorization/execution flags describe that document at preparation, not current permission or an unconsumed run. R3 was subsequently authorized and consumed once per configuration. No action is authorized by this snapshot. The external receipt dossier records retained identities and its access limits; a later public copy cannot create a public timestamp before R3.
