# Included evidence and access limits

This bundle is an explicit selection, not a copy of the project or its history. [PAPER_MANIFEST.json](../release-info/PAPER_MANIFEST.json) lists each approved supporting file and its identity. Its immutable resource companion is the 158-member rc3 subtree with its own original manifest.

Included are the paper, supplement, figure, counter, selected bibliography, aggregate and per-arm metrics, response annotations without message text, context/cost selectors, case/model/environment metadata, versioned M01/M02 CSVs and derived masks, eighty exact no-arguments endpoint channels, selected receipts and their provenance. Only the five previously cited extracts appear as conversation content.

## Deliberate exclusions

| Material | What is retained publicly | Access and consequence |
| --- | --- | --- |
| Complete conversations, tool arguments, reasoning, agent states and raw administrative evidence | Selected metrics, hashes, selectors and five extracts | Originals are retained privately, available to authors/on request subject to access review. Public aggregates cannot reconstruct every trajectory metric. |
| Tested rc2 ZIP and full validation logs/state archive | Exact rc2 receipt, archive hash, 158-entry comparison and 95 executed-component identities | rc2 ZIP and raw records are not in this bundle. No public download or reconstruction of the omitted archive is promised. |
| Full paper/webpage/API verification captures | Titles/authors/versions, primary URLs, original capture hashes and selectors | Obtain papers/pages from their primary sources. Their fulltexts and cached API bodies are not redistributed here. A source hash is an identity, not a public file. |
| Original private GitHub receipt, repository and authorizations | Previously redacted receipt derivative with original and derivative identities | It is not GitHub-signed proof or a new seal. Later publication cannot create a pre-R3 public timestamp. |
| Model weights, wheels, runtimes and VM disks | Artifact/version hashes, requirements and relevant notices | Supply separately under applicable terms. No executable environment, credentials or local machine configuration is bundled. |
| Competition issue text, patches and repository snapshots from M01/M02 | Only the two published measurement/label CSVs, attributed CC BY 4.0, and derived analysis | Competition source data is not redistributed or relicensed. |

`source_file`, `source_identifier`, original-capture identifiers and JSON selectors often name historical originals; they are not automatically relative download links. [DEPENDENCY_INDEX.json](../release-info/DEPENDENCY_INDEX.json) gives a disposition for each file-like reference. Bundled dependencies have a resolved path and hash; historical or runtime identifiers have explicit access/scope labels. Public HTTP links have not been checked in r4.

The archived M01/M02 counting-protocol documents describe their original workflow; referenced intermediate CSVs, full dictionaries and historical scripts are not promised as a complete replay environment here. The two exact published CSVs, explicit criteria, counts, masks, exclusions and IDs suffice to inspect the published-label recount. The historical clean-check note similarly names original analysis files that remain access-limited; its selected result summary and the resource's component-binding receipt are included instead.

Transient `/candidate`, `/environment`, `/usr`, `/tmp` and generic sandbox paths in captures describe execution namespaces. They are retained when evidentiary, not removed as presumed personal information. Original selected captures are unchanged. Local filesystem paths, private repository URLs, credentials, original unsanitized server configurations and unselected conversation content are excluded.

The scientific evidence and licenses do not change. The experimental stage is closed; no future run or publication is authorized by the historical proposal or any receipt in this bundle.
